# OVERVIEW
## HOW SERVER EVOLVED TO CLOUD
- businesses looked for away to reduced cost, use resource more efficiently, application easier to run and scale
## CLOUD BENEFIT
- Scalability : Dễ dàng mở rộng hoặc thu hẹp nếu ứng dụng cần thay đổi
- Dịch vụ theo yêu cầu : Tạo , xóa , lưu trữ server , ko cần chờ phần cứng
- Dùng bao nhiêu trả bấy nhiêu không có phí trả trươvs
- Security : Cung cấp bảo mật
- Có sẵn cao
- Truy cập toàn cầu
## Type Cloud
### Deployment Types
- Public Cloud : dùng cho khởi nghiệp, web, các app toàn cầu vì nó chi phí phải chăng , dễ dàng mở rộng, ko yêu cầu quản lý tầng
- Private Cloud : Dùng cho ngân hàng , hệ thống sức khỏe và chính phủ vì dễ kiểm soát , thiết kế và tuân thủ các vấn đề nhạy cảm
- Hybrid Cloud : Đám mây lai giữa 2 loại trên
### Different way to use cloud
- Iaas : cung cấp phần cứng ảo hóa, (server, network, storage) -> tự xây thêm rồi quản lý chúng ( phục vụ quản trị hệ thống)
- Paas : cung cấp cả hệ điều hành và phần cứng (phục vụ lập trình viên)
- Saas : Cung cấp hoàn chỉnh -> chỉ việc dùng mà thôi ( phục vụ end users)
